# Pounce On It — public site

Static site for the Pounce On It Chrome extension, published with GitHub Pages:
the product landing page and the privacy policy the Chrome Web Store links to.

- `index.html` — landing page
- `privacy.html` — privacy policy (linked from the CWS listing)
- `assets/` — icon, cat artwork, self-hosted Overpass fonts (OFL; see `assets/OFL.txt`)
- `style.css` — shared styles

No build step, no JavaScript, no third-party requests.

Published at <https://out-of-office-travels.github.io/pounceonit/>.
